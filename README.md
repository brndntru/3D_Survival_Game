# The Whiteout
CS 4700 Final Project
3D Survival Game
Hank Cao, Brandon Trieu

## Setup
1) Download zip or clone repository -> Play in Unity editor
2) Download zip of build from itch.io: https://scoopakoopa.itch.io/the-whiteout

## Features
- Scenes: Main Menu (start), World (Game), Game Over (death)
- Movement: WASD (move), Shift (sprint), Spacebar (jump), Left-Click (attack)
- Interactable Items (F key to pick up)
- Inventory System & Hotbar
- Combat System: Swappable weapons, enemy AI, player and enemy health (w/ health bar and damage indicator), weapon and enemy animations
- Freeze System: Gradually increasing freeze bar, firepit with warm zone, health damage upon reaching full freeze, GUI freeze indicator
